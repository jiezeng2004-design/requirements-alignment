# Tasks that should not trigger alignment

These existing or explicit tasks should normally proceed without interrupting the user.

1. **README version edit** — “README 里的 0.1.0 改成 0.1.1。”
2. **Clear null bug** — “修复这个明确的 null pointer bug。”
3. **Formatting** — “格式化这个文件。”
4. **Typo fix** — Correct an obvious spelling error.
5. **Local rename** — Rename a private helper and update its references.
6. **Established architecture** — Add a small model using the database and repository pattern already used throughout the project.
7. **Safe engineering detail** — Place a helper, choose `map` versus `for`, or follow the repository's ordinary library and file-layout conventions.
